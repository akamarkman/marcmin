# MARCmin

**Smaller models that read can beat bigger models that memorize.**

A research project by [Chris Markman](https://github.com/akamarkman) on using library
catalogs (MARC records) to give small AI models a map to read by.

- Site: https://akamarkman.github.io/marcmin/
- Phase 1 test kit: `experiments/phase-1/marcmin-phase1-kit.zip`

This repository holds the published website. It is plain HTML, served by GitHub Pages.
