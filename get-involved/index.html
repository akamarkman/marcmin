MARCmin · Get involved

Get involved

MARCmin tests whether small AI models can find and read books by using the map libraries already built. It is an open, early-stage project, and there are many ways to help.

Led by Chris Markman · github.com/akamarkman

Ways to help

Pick whatever fits. Small contributions count.

Catalogers and librarians

You know how records are made and how patrons really ask.

  • Review test questions and judge which records answer them
  • Share anonymized reference questions
  • Flag records the pre-encoder reads wrong

Libraries

Real collections are the strongest evidence.

  • Share a catalog export for testing
  • Try a small, offline search device at a branch
  • Connect us with your catalogers

Researchers

Retrieval, digital libraries and information science.

  • Point out related work
  • Review the methods and evaluation
  • Co-author, review a draft or endorse a preprint

Developers

Small models, search and low-power hardware.

  • Review the code as it is released
  • Test on a Raspberry Pi or mini PC
  • Help run the Library of Congress benchmark

Funders and institutions

Small, efficient AI for public institutions.

  • Partner on a funding application
  • Support the open test set and tools

Everyone else

Interest is help too.

  • Share the site with a librarian you know
  • Send questions or ideas
